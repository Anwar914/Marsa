# Marsa (مرسى) – Technical English & 3D Car Anatomy

Learn automotive engineering in English: explore a 3D car, hear and practise the technical terms, and prepare for your Technical English exam – in one app with one progress overview.

**Live app:** https://marsa-english.streamlit.app/

## What is inside
| Tab | Content |
|---|---|
| **Explore / Learn / Quiz** | Interactive 3D car (12 modules: exterior, interior, engine with four-stroke animation, I4/V6/V8, brakes, suspension, drivetrain, tyres, electrical, filters, jack, wipers). 146 bilingual EN/DE terms with IPA, audio, explanations A1–B2, seven quiz modes, spaced repetition. |
| **Course** | Technical English workspace: modules 1–6, vocabulary trainer, *My mistakes*, B1 grammar (20 topics) and B2 grammar (16 topics) with word-order and error-correction exercises, final level tests, reading, writing, two 90-minute practice exams, games, study plan. |
| **Progress** | Shared streak, 14-day activity chart, 3D vocabulary, course readiness, worksheets, grammar units and test results. |

Grammar explanations and exercises are original material. Practice exams are not a confirmed official format; free writing uses sample answers and self-assessment. Progress is stored in the browser.

## Files
| File | Purpose |
|---|---|
| `streamlit_app.py` | Streamlit host: shows `AutoAnatomy3D.html` full-width |
| `AutoAnatomy3D.html` | The complete app (built from `app-source/`, works offline too) |
| `Marsa.html` | The Technical English course on its own (offline), generated by `build.py` |
| `index.html`, `style.css`, `data.js`, `games.js`, `app.js` | Sources of `Marsa.html` |
| `app-source/` | React + Three.js source of the full app (the course is `app-source/src/course/Lernseite.html`) |

## Run locally
```sh
pip install -r requirements.txt
streamlit run streamlit_app.py
```
Or open `AutoAnatomy3D.html` / `Marsa.html` directly in Chrome or Edge.

## Rebuild after changes
```sh
cd app-source && npm install && npm run build:single   # writes ../AutoAnatomy3D.html
```
Grammar content: edit `app-source/tools/grammar_content.py`, run it, then see `app-source/tools/patch_grammar.py`.
Course sources: after changing `index.html`/`*.js`/`style.css`, run `python build.py` to regenerate `Marsa.html`.

## Deploy
Streamlit Community Cloud: repository `Anwar914/Marsa`, branch `main`, file `streamlit_app.py`. Every push to `main` redeploys. No API keys required.
